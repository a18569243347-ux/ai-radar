# 零基础上手指南（保姆级）

> 假设你从未做过小程序、没用过 Git/GitHub。每个概念第一次出现都会解释。
> 平台界面经常改版，截图路径以「菜单名」为准，找不到就用页面里的搜索框搜关键词。
> 走完本指南，你的小程序就上线了。全程大约 3-5 个「工作时段」，其中备案审核（1-2 周）是唯一需要等待的，其余都可以并行。

---

## 0. 开始前的准备

**你需要有：**
- 这台 Windows 电脑（已有）
- 一个**没注册过微信公众平台**的邮箱（QQ 邮箱可以）
- 本人身份证 + 本人微信（注册用）
- 一张本人银行卡（部分注册流程会验证，备着）

**你会遇到的概念（先混个眼熟，后面都会用到）：**

| 概念 | 一句话解释 |
|---|---|
| 小程序 AppID | 小程序的身份证号，一串 `wx` 开头的字母数字，注册后才有 |
| 备案 | 国家要求：小程序上架前要在工信部登记，在微信公众平台里免费办理 |
| 微信开发者工具 | 官方的"编辑器+模拟器"，写代码、看效果、上传都靠它 |
| Git | 代码的"存档系统"，每次改动可以存档、回滚 |
| GitHub | 放 Git 存档的网站，同时负责每 30 分钟自动抓价格（称为 CI / Action） |
| 云开发 | 微信官方的"云端数据库"，让价格更新不用重新提审就能到用户手机 |
| JSON | 本项目存价格数据的文件格式，用记事本就能改 |

**本项目文件在哪里做什么（只需要知道这几个）：**
```
D:\Zcode cache\AI雷达\
├── data\            ← 价格数据都在这里（你要核对修改的地方）
├── miniprogram\     ← 小程序界面代码（一般不用动）
├── cloudfunctions\  ← 云函数（部署时右键点两下）
├── crawler\         ← 自动抓价格的脚本（不用动）
└── docs\            ← 文档（本文件、合规清单、上线清单）
```

## 1. 注册小程序账号（约 30 分钟）

1. 浏览器打开 **mp.weixin.qq.com**，右上角「立即注册」。
2. 选择 **「小程序」** 这个方块。
3. 填写邮箱（没注册过公众平台的）→ 去邮箱点激活链接 → 设置密码。
4. 主体类型选择：**个人**。
5. 主体信息登记：填你的身份证姓名、身份证号 → 管理员信息：用你本人的微信扫码确认、填手机号收验证码。
6. 填写小程序信息：
   - **名称**：先试「AI雷达」，被占用就换近似的（如「AI价格雷达」）。名称全网唯一。
   - **头像**：项目里已备好现成图标 `assets/app-icon.png`（雷达+价格标签那张），注册时上传它。
   - **简介**：`查询主流 AI 大模型 API 与订阅价格的信息工具，数据来自公开官方页面`
   - ⚠️ 名称和简介**不要**出现「最全/第一/最低价」这类词，会过不了。
7. 注册完成后，**记住 AppID**：登录公众平台 → 左侧「开发」→「开发管理」→「开发设置」→ 复制 AppID（wx 开头那串）。后面要用两次。

## 2. 提交备案（今天必须启动，审核 1-2 周）

> 为什么：2023 年起国家要求所有小程序上架前完成 ICP 备案，不备案无法提审上线。免费，全程在公众平台里办。

1. 登录 **mp.weixin.qq.com** → 左侧「设置」→「基础设置」→ 找到「小程序备案」→「去备案」。
2. 按向导填写：
   - 主体信息：你的身份证信息（同注册）
   - **服务内容选择**：选「信息查询」或「工具」类目相关的选项；**绝对不要**选电商、资讯、社区类。
   - 服务内容说明可以写：`查询公开的 AI 模型价格信息，不涉及交易，不提供内容发布`
   - 负责人：你自己，需要**人脸核身**（手机上完成）。
3. 提交后先过微信初审，再转到省通信管理局审核，总共约 1-2 周。
4. **期间可能接到 010 或本地固话打来的核实电话**，如实回答即可：「做一个查询 AI 模型价格的信息工具，不卖东西，不让用户发内容」。
5. 备案是等待审核，**下面第 3-7 步现在就可以做，不要干等**。

## 4. 推送到 GitHub（约 30 分钟）

> 为什么：GitHub 上一项功能叫 Actions，会替你**每 30 分钟自动去各家官网核对价格**、自动更新数据。本项目已经写好了这套流程，你只需要把代码传上去。

1. 注册 GitHub：打开 **github.com** → Sign up → 用邮箱注册，用户名随便起（后面会用到，记为 `你的用户名`）。
2. 新建仓库：登录后右上角 **「+」→ New repository**：
   - Repository name：`ai-radar`
   - 选 **Public**（公开仓库 Actions 完全免费；介意公开就选 Private，功能一样，免费额度也够）
   - 下面所有勾选框（README、license 等）**全部不勾**（我们已经有了）
   - 点绿色按钮 **Create repository**
3. 在本机提交并推送。打开 **Git Bash**（开始菜单搜 Git Bash），逐行粘贴执行（注意替换两处中文）：
   ```bash
   cd "/d/Zcode cache/AI雷达"
   git config --global user.name "你的名字"        # 随便起，显示在提交记录里
   git config --global user.email "你的邮箱"
   git commit -m "init: AI雷达小程序（代码+数据+自动更新）"
   git remote add origin https://github.com/你的用户名/ai-radar.git
   git branch -M main
   git push -u origin main
   ```
   - 我已经帮你完成了 `git init` 和文件暂存，所以上面没有 `git add` 这步，直接 commit 即可。
   - `git push` 时会弹窗要求登录 GitHub → 选「Sign in with your browser」→ 浏览器里点授权。
   - 报错 `remote origin already exists` → 说明之前加过，跳过那一行继续。
4. 验证：浏览器刷新你的仓库页面 `https://github.com/你的用户名/ai-radar`，能看到所有文件就成功了。

## 5. 验证自动更新链路（约 10 分钟）

1. 打开你的仓库页面 → 顶部 **Actions** 标签 → 如果出现绿色按钮「Enable workflows」就点它。
2. 左侧列表点 **price-sync** → 右侧 **Run workflow ▼** → 绿色 **Run workflow**。
3. 等约 1-2 分钟，列表里出现一条记录：
   - **绿色 ✓**：成功。点进去 → 点「构建数据集」步骤，日志里会看到 `CHANGED ...` 或 `UNCHANGED ...`（首次运行是 CHANGED，属正常）、`source: openrouter: ...` 等。
   - **红色 ✗**：点进去看哪一步红字。多数是网络抖动 → 点右上「Re-run jobs」再跑一次；持续失败就把日志内容发给 ZCode 帮你分析。
4. 成功后它会自动每 30 分钟跑一次，不用再管。价格变了 → 自动提交新数据 + 自动同步云端（配完第 8 步后）；没变 → 什么都不发生。
5. 注意：仓库 60 天没有任何动静，GitHub 会暂停定时任务并发邮件提醒——到时候随便改个文件推上去就恢复了。

## 6. 核验种子价格（最重要的实质工作，2-4 小时）

> 为什么：App 里现在的价格是「种子数据」，分两类需要人工确认——2026 现役旗舰（GPT-6、Claude Opus 5 等）用的是聚合平台参考价（≈官方价+服务费）；豆包/百度/腾讯/阶跃是 2025 年的存量价。**价格不准是这类产品最致命的问题**，所以这步必须做。

1. 用 **VS Code**（官网 code.visualstudio.com 下载，比记事本好用）或记事本打开 `data\models.json`。
2. 逐条核对：每条记录里有 `official_url`（官方定价页地址）→ 在浏览器打开 → 找到对应模型 → 对比「输入/输出 每百万 tokens」两个数字。
3. 优先核 `note` 里带这些字样的（最可能不准）：
   - 「参考 OpenRouter 价」「国际站参考价」「由聚合平台参考价折算」→ 2026 旗舰价
   - 「2025 参考价，需核验」→ 豆包 / 百度 / 腾讯的条目
4. 改动方法：把 JSON 里的 `input_per_mtok` / `output_per_mtok` 数字改成官网的最新值，然后把这条的 `"verified": false` 改成 `"verified": true`。
   - ⚠️ JSON 格式很严格：只改数字，别动引号、逗号、冒号。
5. 顺手核一遍 `data\plans.json`（订阅计划价格），同样改数字 + 改 verified。
6. 全部核完后，打开 `data\meta.json`，把 `"status": "seed-pending-review"` 改成 `"status": "reviewed"` —— 小程序里「数据待核验」的黄色角标会消失。
7. 让改动生效（二选一）：
   - **简单**：什么都不用做，直接跳到第 8 步推送。CI 会在半小时内自动重建数据并同步。
   - **想立刻看效果**：Git Bash 里执行 `cd "/d/Zcode cache/AI雷达" && perl tools/build_offline.pl`（我确认过你电脑里有 perl），它会重建 `dist\dataset.json` 和小程序内置数据。
   - （以后装了 Python 就用标准命令 `python -m crawler.crawl`，功能一样且带联网抓取）
8. 提交推送：
   ```bash
   cd "/d/Zcode cache/AI雷达"
   git add . && git commit -m "data: 核验种子价格" && git push
   ```
9. **偷懒通道**：这一步可以整个交给我——跟我说「帮我核验价格」，我会访问各官网逐条核对并直接改好文件，你过目后自己推送就行。

## 8. 后端接入（备案通过后、提审前做，约 1 小时）

> 为什么：现在价格更新要靠「发新版本」（每次都要提审）。配上后端后，CI 抓到新价格直接写进数据库，**用户下次打开小程序就是新价格，不用提审**。

**三条路线任选其一（都已在代码里支持，切换只改配置）：**

- **路线 A · 什么都不配（¥0）**：跳过本步。小程序用打包内置数据，价格变化时 CI 会自动更新仓库，你重新上传+提审即可。验证期完全够用。
- **路线 B · Cloudflare Workers（¥0，推荐给已有 CF 账号的人）**：如果你已有一个跑在 Workers 上的小程序，5-10 分钟就能把这个项目也接上——完整步骤见 `worker/README.md`（部署 Worker → 建一个 KV → 配 GitHub Secrets → 改 dataService.js 的 BACKEND 配置）。前提是所用域名已备案。
- **路线 C · 微信云开发**（下面是完整步骤，适合想全用微信体系的情况）：

1. 开通：开发者工具顶部点 **「云开发」** 按钮 → 同意协议 → 开通 → **创建环境**，名字随意 → 记下**环境 ID**（一串字母数字，形如 `cloud1-xxxxxxxx`）。
   - **费用（2026-09 查证）**：新用户可**免费体验基础套餐**（官方活动，截至 2026-12-31）；免费体验环境到期可续期（单次续 6 个月，需手动操作，不支持自动续费）。基础套餐原价 ¥19.9/月、含 40,000 资源点/月——本项目的用量（每次打开小程序查 1 次数据 + 每天几十次数据同步）远低于这个额度，就算有几千日活也用不完。最坏情况自费也就是 ¥19.9/月；再想省到零，可以完全不配云开发（架构会自动回退到内置数据，代价是价格更新要随版本提审）。以控制台实际显示为准。
2. 建数据集合：云开发控制台 → 左侧「数据库」→ 「+」添加集合 → 名称填 `datasets` → 权限选「仅创建者可读写」→ 确定。（放心，用户读数据走云函数，不受这个权限限制。）
3. 部署两个云函数：回到开发者工具主界面，左侧文件树找到 `cloudfunctions\importData` → **右键 → 「上传并部署：云端安装依赖（不上传 node_modules）」** → 等右下角提示成功。再对 `cloudfunctions\queryData` 做同样操作。
   - 看不到 cloudfunctions 目录？工具顶部工具栏确认「云开发」图标旁的环境已选中你刚创建的环境。
4. 给 `importData` 设密码：云开发控制台 → 「云函数」→ 点 `importData` → 「函数配置」→「环境变量」→ 添加一条：
   - 名称：`SYNC_TOKEN`
   - 值：自己编一串长随机字符（比如 `radar-2026-xK9mPq2wVt7s`）→ **保存好**，后面还要用。
5. 开通 HTTP 触发：云开发控制台 → 左侧找「**HTTP 访问服务**」（有的版本叫「云接入」）→ 创建/新建路由 → 关联函数选 `importData` → 路径随便（如 `/import`）→ 保存后得到一个 `https://` 开头的**触发 URL** → 复制保存。
6. 本地测试一次（Git Bash，注意替换引号里内容）：
   ```bash
   export CLOUD_IMPORT_URL="刚才复制的触发URL"
   export SYNC_TOKEN="刚才设置的token值"
   python -m crawler.sync
   ```
   没有 Python 就用等价命令：
   ```bash
   curl -X POST -H "Content-Type: application/json" -H "x-sync-token: 你的token" \
        --data-binary @dist/dataset.json "你的触发URL"
   ```
   返回 `{"ok":true,...}` 就通了。
7. 告诉小程序用哪个环境：打开 `miniprogram\app.js`，把 `YOUR-CLOUD-ENV` 换成第 1 步的环境 ID，保存。
8. 验证：开发者工具重新编译 → 点「关于」tab → 「数据状态」一行应显示 **「云端数据」**。
9. 接到 CI（自动化最后一块拼图）：GitHub 仓库页面 → **Settings → Secrets and variables → Actions** → 绿色「New repository secret」→ 分两次添加：
   - Name: `CLOUD_IMPORT_URL`，Secret: 第 5 步的触发 URL
   - Name: `SYNC_TOKEN`，Secret: 第 4 步的 token
   配完之后，CI 一旦发现价格变化就会自动写进云数据库，全程无人值守。

## 9. 提交审核（备案通过后）

**提审前自检清单：**
- [ ] 备案状态：已通过（公众平台「设置→基础设置」可查）
- [ ] `data/meta.json` 的 status 已是 `reviewed`（App 里没有黄色"待核验"角标）
- [ ] 真机预览五个页面都正常
- [ ] 「关于」页能看到免责声明和数据来源

**提审步骤：**
1. 开发者工具顶部点 **「上传」** → 填版本号 `1.0.0` 和备注 → 上传成功。
2. 登录 **mp.weixin.qq.com** → 「开发」→「开发管理」→「版本管理」→「开发版本」里能看到刚上传的版本 → 点 **「提交审核」**。
3. 审核信息填写：
   - **服务类目**：`工具 → 信息查询`（个人主体可用类目里选这个）
   - **功能页面**：选价格对比页
   - **测试说明/备注**（重要，直接给审核员看）：`本小程序是纯信息查询工具：展示从各 AI 官网公开页面整理的模型与订阅价格，每条数据标注官方来源与更新时间，不提供交易、不提供用户发布内容、不内置 AI 生成功能。`
4. 提交后通常 1-3 天出结果。
5. **被拒很正常，不用慌**：看拒绝理由 → 对照 `docs\launch-checklist.md` 底部的「常见拒审原因对照」修改 → 重新提审即可，不影响账号。
6. 审核通过 → 回到「版本管理」→ 该版本旁点 **「发布」** → 上线 🎉

## 10. 上线后

1. **看数据**：公众平台 →「统计」→ 能看到访问人数（UV）。累计 **1000** 后：「推广」→「流量主」→ 开通，可在页面里挂官方广告赚钱（个人主体唯一的变现方式，本项目的页面结构已预留了 footer 广告位位置）。
2. **日常维护（基本无人值守）**：
   - GitHub Actions 每半小时自动抓价格、自动更新，有红叉才需要管；
   - 偶尔看一眼 CI 日志里的 `drift:` 行——那是「聚合平台价和官网价差超 25%」的提醒，说明某家官网调价了，去核对一下种子数据即可。
3. **第二版功能建议顺序**（数据都已就绪或半就绪）：
   - 合规聚合平台比价页（OpenRouter 价格已在自动采集，只差一个前端页面）
   - 跑分排行榜（引用 LMArena 等公开榜单，注意标注来源）

## 遇到问题怎么办

| 现象 | 先看哪里 |
|---|---|
| 开发者工具报错/白屏 | 工具底部「调试器」→ Console 红字 |
