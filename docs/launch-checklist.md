# 上线 Checklist（个人主体）

从零到上架的完整路径，按顺序执行。

## 第 1 步：注册与备案（与开发并行，耗时最长）

- [ ] 注册个人主体小程序：mp.weixin.qq.com → 立即注册 → 小程序（身份证 + 本人银行卡）
- [ ] 名称建议「AI雷达」（或查重后近似名）；头像自制，不用任何品牌 logo
- [ ] **完成小程序备案**：公众平台 → 设置 → 基础设置 → 小程序备案（免费，约 1-2 周）
- [ ] 备案服务内容选「信息查询/工具类」，与实际功能一致

## 第 2 步：本地开发与核验数据

- [ ] 微信开发者工具导入本目录，替换 `project.config.json` 的 appid
- [ ] 真机预览五个页面（首页 / 价格 / 订阅 / 免费 / 关于）
- [ ] **逐条核验 `data/*.json` 种子价格**（重点：2026 现役旗舰与豆包/百度/腾讯/阶跃条目），核完改 `verified: true`
- [ ] 全部核验后把 `data/meta.json` 的 `status` 改为 `reviewed`
- [ ] 重建数据：`python -m crawler.crawl`（或 `perl tools/build_offline.pl`）

## 第 3 步：云开发（可选，推荐）

- [ ] 开发者工具 → 云开发 → 开通（个人主体可用，有免费额度）
- [ ] 创建集合 `datasets`；部署 `importData`、`queryData` 两个云函数
- [ ] `importData` 环境变量：`SYNC_TOKEN=<随机长字符串>`
- [ ] 云开发控制台 → HTTP 访问服务 → 给 `importData` 绑定触发 URL
- [ ] `miniprogram/app.js` 替换 `YOUR-CLOUD-ENV` 为真实环境 ID
- [ ] 手动触发一次导入验证：
  ```bash
  set CLOUD_IMPORT_URL=<触发URL> && set SYNC_TOKEN=<token> && python -m crawler.sync
  ```
- [ ] 小程序里确认「关于」页数据来源显示「云端数据」

## 第 4 步：接 GitHub 自动化

- [ ] 仓库推到 GitHub（Actions 默认开启）
- [ ] 手动触发一次 price-sync 工作流确认绿灯（首次会提交快照）；再触发一次，确认输出 UNCHANGED、不产生新提交
- [ ] （可选）Secrets 配置 `CLOUD_IMPORT_URL` + `SYNC_TOKEN`，实现自动入库（有变化才写）

## 第 5 步：提审

- [ ] 服务类目：**工具 → 信息查询**（个人主体可用类目里选）
- [ ] 页面截图：避免出现「比某某便宜」等对比性文案与第三方 logo
- [ ] 简介：「查询主流 AI 大模型 API 与订阅价格的信息工具，数据来自公开官方页面」
- [ ] 审核回复话术准备：说明「纯信息展示、无交易、无 UGC、数据均标注官方来源、每日更新」
- [ ] 提交审核；若被拒，按拒审理由修改（常见原因：类目不符 / 名称问题 / 截图含违禁词）

## 第 6 步：上线后

- [ ] 配置「订阅消息」可选项：价格变动提醒（后续版本）
- [ ] UV 攒到 1000 → 开通流量主（个人主体可开）
- [ ] 定期看一眼 CI 漂移报告，复核超阈值条目（价格页解析失败时 CI 日志会有提示）
- [ ] 第二版迭代顺序：聚合平台比价页（数据已就绪）→ 跑分排行榜 → 省钱攻略

## 常见拒审原因对照

| 拒审理由 | 对策 |
|---|---|
| 类目与服务不符 | 保持纯信息展示，删掉任何交易/社区迹象 |
| 内容含违禁词 | 构建期校验已拦截绝对化用语；检查页面文案 |
| 涉及第三方品牌侵权 | 不用 logo、不暗示官方合作，指明数据来自公开页面 |
| 需要资质 | 不要出现「行情」「投资」「汇率交易」等金融类表述（汇率仅作换算说明） |
