# 合规清单（AI雷达）

> 本文档是产品红线。功能迭代时对照自查；拿不准的内容宁可不加。

## 一、最大的红线：不收录「中转站」

API 中转站（转售 OpenAI/Anthropic 等官方 API 的站点）存在多重问题：

1. **违反上游服务条款**：OpenAI 明确禁止未经书面批准转售、共享 API 密钥；多数大厂条款类似。
2. **监管整治中**：国家安全部 2026 年 6 月发布风险提示，中转站市场面临整治（运营资质缺失、隐私泄露、数据倒卖）；提供生成式 AI 服务还涉及大模型备案与数据出境评估。
3. **刑事边界**：逆向网页接口包装为 API、批量注册账号套取免费额度转售，可能涉嫌非法获取计算机信息系统数据罪。
4. **平台后果**：小程序收录、推荐这类服务，会面临审核被拒、下架、主体处罚；用户被骗还可能有连带责任。

**替代方案（已实现）**：`aggregators` 只收录合规平台——有官方授权、条款公开透明的聚合网关（OpenRouter）、合规云平台（硅基流动）、厂商官方站点（百炼国际站）。每条必须带 `compliance_note`（校验器强制）。

## 二、小程序自身

| 事项 | 要求 |
|---|---|
| 主体 | 个人主体可做；类目范围窄、无微信支付 |
| 小程序备案 | 上线前必须在微信公众平台完成备案（免费） |
| 类目 | 建议「工具-信息查询」；服务内容必须与类目一致，不要挂电商/资讯类目 |
| 变现 | 流量主广告（个人主体 UV≥1000 后可开通）；不做代充、代购、拼车等交易功能 |
| web-view | 个人主体不可用，外链一律用「复制链接」（已实现） |
| 名称 | 避免「最全 / 第一 / 官方」等词；「AI雷达」可用 |

## 三、内容合规

1. **广告法**：不得使用绝对化用语（最全/最低价/最便宜/第一/最好）。`crawler/validate.py` 会在构建期扫描全部数据并拦截。
2. **来源标注**：每条价格必须带 `official_url`（校验器强制）；页面展示更新时间与数据状态。
3. **免责声明**：全站固定「价格仅供参考，以官方页面为准；不构成购买建议」（见 `data/meta.json` 的 `disclaimer`，关于页展示）。
4. **榜单口径**：所有排序（按输入价/输出价）必须展示排序口径；不生成综合「排名榜」式结论，避免被认定为变相评比广告。
5. **省钱攻略（第二版）**：只写官方渠道——免费层、年付折扣、学生计划、官方促销、提示词缓存、离峰计费。
   **禁止**：VPN 区域套利、共享/合租账号、逆向接口、薅免费额度矩阵等违反服务条款的内容。
6. **商标**：提及品牌名属于指示性使用，可以；不要使用品牌 logo 作装饰，不要让页面看起来像官方出品。

## 四、数据采集合规

| 规则 | 本仓库的实现 |
|---|---|
| 只抓公开定价页（事实性数据） | sources 只访问官方 pricing 页 |
| 遵守 robots 协议 | `deepseek.py` 抓取前用 `robotparser` 检查 |
| 控制频率 | 每 30 分钟一轮（有变化才落库）、每源每轮仅 1 个请求、urllib 直连无并发，日均请求量远低于搜索引擎爬虫 |
| 自报身份 | 统一 User-Agent（上线前把 `set-your-email` 换成真实联系方式） |
| 不绕过反爬 | 无登录、无验证码破解；JS 渲染页一律人工维护种子 |
| 不抓个人信息 | 只涉及价格数字 |
| 不二次倒卖数据集 | 数据仅供本小程序展示；开源时注意仓库可见性设置 |
| 失败回退 | 抓取失败保留种子数据，绝不臆造 |

**跑分数据（第二版）**：引用 LMArena / Artificial Analysis 等需遵守其引用条款，逐条标注来源与更新日期，不修改原始数值。

## 五、不要触碰的功能

- ❌ 内置 AI 对话 / 生成（会触发《生成式人工智能服务管理暂行办法》备案，个人主体无法完成）
- ❌ 任何支付、代充、账号交易
- ❌ 中转站收录、跳转、推广
- ❌ 用户生成内容（评论/UGC，需要额外审核义务）
- ❌ 抓取/展示各平台的登录态数据、用户数据

## 六、内容更新纪律

- 每天 CI 自动抓取 + 漂移报告（`meta.drift_report`），漂移超 25% 的条目人工复核；
- `meta.json` 的 `changelog` 记录数据修正历史；
- 收到厂商投诉/平台通知时，第一时间下架对应内容并记录处理过程。
